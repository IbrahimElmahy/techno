# قواعد التحويل للفصحى (إلزامية)

1. كل نص يظهر للمستخدم يُكتب بالعربية الفصحى لا العامية المصرية: العناوين، الأزرار، تسميات الحقول، رؤوس الأعمدة، النصوص الإرشادية داخل الحقول (placeholder)، رسائل النجاح والخطأ والتحذير (message / notification / Modal.confirm / Popconfirm)، حالات «لا توجد بيانات»، رسائل التحقق، عناوين الطباعة والتصدير، ورسائل الخادم (HTTPException وأخطاء الخدمات التي تصل للمستخدم).
   أمثلة: «ماقدرتش أحفظ» ← «تعذر الحفظ»، «مافيش» ← «لا يوجد»، «مينفعش» ← «لا يمكن»، «اتحفظ» ← «تم الحفظ»، «اتمسح» ← «تم الحذف»، «اختار» ← «اختر»، «عايز» ← «تريد / يجب»، «دلوقتي» ← «الآن»، «إيه» ← «ما»، «ليه» ← «لماذا»، «كده» ← «هكذا»، «هيتعمل» ← «سيتم»، «مش» ← «ليس / غير / لا»، «اللي» ← «الذي / التي / الذين»، «ده / دي» ← «هذا / هذه»، «عشان» ← «لأن / لكي»، «لسه» ← «لم … بعد»، «تاني» ← «آخر / مرة أخرى»، «بتاع» ← إضافة صحيحة، «مالكش صلاحية» ← «ليس لديك صلاحية»، «أيوه / لأ» ← «نعم / لا»، «تليفون» ← «هاتف».
2. تبقى كما هي: أسماء البيانات والمصطلحات التجارية للعميل («أبيض»، «بولي»، «تكنو»، أسماء الأصناف والفئات والحسابات، «كشف حساب»، «سند قبض»، «كارت الصنف»)، وأسماء القائمة المأخوذة من نظام a5 (مثل «اداره المبيعات»، «اذن تحويل مخازن») إلا إذا كانت عامية صريحة.
3. حذف النصوص الشارحة من الشاشات: خاصية `subtitle` الشارحة في ListPage، أسطر `extra=` التي تشرح فقط، تنبيهات Alert التي تشرح طريقة عمل الشاشة فقط، أيقونات المساعدة، الفقرات الإرشادية. تبقى: تسميات الحقول، البيانات، رسائل الأخطاء والتحقق، التنبيهات التي تعبّر عن حالة حقيقية (أرقام أو وضع فعلي)، تلميحات أزرار الأيقونات مختصرة لاسم الإجراء.
4. لا تعليقات في الكود إطلاقاً (لا تضف أي تعليق).
5. لا تغيير في السلوك: لا تغيّر نصاً تقارنه الشيفرة أو ترسله للخادم أو يُخزَّن (قيم enum، مفاتيح، قيم مثل «معاينة»/«مرمة»/«أبيض»/«بولي»، أوصاف قيود مخزنة، نصوص تُطابَق في مكان آخر). ابحث بـ grep قبل تغيير أي نص مشكوك فيه. لا تعيد تسمية متغيرات أو مفاتيح أو مسارات. احذف الاستيرادات التي تصبح غير مستخدمة.
6. اعمل بنفسك مباشرة ملفاً ملفاً. لا تشغّل وكلاء فرعيين (sub-agents) ولا تسلّم تقريرك قبل الانتهاء الكامل من كل ملفات نطاقك.
7. بعض الملفات في نطاقك ربما عُدّلت جزئياً من قبل؛ راجعها كاملة وأكمل الناقص.
8. لا commit ولا push ولا نشر. لا اختبارات ولا كتابة اختبارات.
