# دليل وظائف تطبيق المعاينات - TechnoTherm (PDA)

## 1. مقدمة
تم تصميم تطبيق **TechnoTherm - المعاينات** لتسهيل عمل الفنيين ومندوبي الشركة في الميدان. يعمل التطبيق كمنصة محمولة (PDA) تتيح جمع البيانات، تسجيل المعاينات، وإدارة المهام حتى في حالة عدم توفر اتصال بالإنترنت (Offline-first)، مع مزامنة البيانات لاحقاً بمجرد توفر الاتصال.

## 2. الميزات الرئيسية

### 2.1. العمل بدون إنترنت (Offline Mode)
- يعتمد التطبيق على قاعدة بيانات محلية (SQLite) لحفظ كافة المعاينات والمهام.
- يمكن للمندوب تسجيل الدخول والعمل بشكل طبيعي في الأماكن التي لا تحتوي على شبكة.
- يتم تخزين المهام في "سجل الانتظار" (Pending Queue) حتى يتم الاتصال بالإنترنت والمزامنة.

### 2.2. تسجيل الدخول الذكي
- التحقق من بيانات المستخدم عبر السيرفر `api.technothermeg.com`، وفي حال تعطل السيرفر الرئيسي ينتقل لخوادم بديلة أو يعتمد على المصادقة المحلية.
- **الحسابات الافتراضية للتجربة:** (`rep`, `admin`) مع كلمة مرور `123`.

### 2.3. لوحة المعلومات والمهام السريعة (Dashboard)
- تعرض الصفحة الرئيسية إحصاءات محدثة لعمل الفني:
  - عدد الزيارات المنجزة.
  - النقاط المكتسبة (Gamification/KPIs).
  - عدد الملفات المعلقة التي تنتظر المزامنة.
- قائمة إجراءات سريعة لتسريع العمل الميداني.

---

## 3. العمليات الأساسية

### أ. المعاينات الميدانية (زيارات الفنيين)
- **الهدف:** توثيق حالة المواقع والأجهزة في الميدان.
- **المدخلات:**
  - اسم العميل وعنوانه التفصيلي (المدينة، الحي).
  - رقم الهاتف المحمول.
  - الملاحظات الفنية للمعاينة.
  - التقاط صور للمعاينة ورفعها (مع إمكانية تحديد ما إذا كان قد تم التأسيس/التركيب).
- **النتائج:** يتم حفظ نموذج المعاينة وإرفاق الصور محلياً.

### ب. الزيارات الدورية (المعارض)
- **الهدف:** توثيق الزيارات التسويقية لمعارض الموزعين والعملاء.
- **المدخلات:**
  - نوع الزيارة: زيارة عادية، تسليم بضاعة، أو تحصيل نقدية.
  - اسم المعرض والمحافظة.
  - الملاحظات.

### ج. الكوبونات والمكافآت
- **الهدف:** إدارة الحوافز وتسليم الكوبونات.
- **المدخلات:**
  - يتم إدخال كود الكوبون وقيمته.
  - يتم احتساب الكوبونات ضمن النقاط المكتسبة للفني.

### د. إدارة المزامنة (Sync)
- **الهدف:** رفع كافة البيانات المحلية إلى السيرفر الرئيسي.
- **الآلية:** 
  - صفحة مخصصة تظهر المهام المعلقة (معاينات، زيارات دورية، كوبونات).
  - زر لمزامنة الكل يرسل حزم البيانات إلى واجهة الـ API ويحدث حالة الملفات إلى "مكتملة".

## 4. الهوية البصرية وتجربة المستخدم
- يعتمد التطبيق تصميم احترافي بالكامل متوافق مع اللغة العربية (RTL).
- ألوان مستمدة من هوية الشركة (أخضر تكنوثرم وبرتقالي).
- واجهة مستخدم تفاعلية بخط `Cairo` الواضح والحديث.
