# وكيل جهاز البصمة (ZKTeco K40)

برنامج صغير يعمل على حاسوب داخل شبكة الشركة، يقرأ البصمات من جهاز البصمة
ويرسلها إلى النظام كل خمس دقائق. يُثبَّت على الحاسوب نفسه الذي يعمل عليه برنامج
ZKTeco Attendance Management. الوكيل يقرأ فقط ولا يمسح سجل الجهاز ولا يعدّله.

## ١. في النظام

1. الحضور والانصراف ← تبويب «أجهزة البصمة» ← «إضافة جهاز».
2. الاسم، الرقم التسلسلي `A8N5184661794`، العنوان `192.168.1.201`، المنفذ `4370`، والفرع.
3. بعد الحفظ تظهر نافذة فيها **عنوان الخادم** و**رمز الربط** — انسخهما الآن،
   فالرمز لا يظهر مرة ثانية (زر «إظهار رمز الربط» يُنشئ رمزاً جديداً ويوقف القديم).
4. في بطاقة كل موظف اكتب «رقم البصمة» = رقمه على الجهاز
   (أو من «مستخدمو الجهاز» ← «ربط بموظف» بعد أول مزامنة).

## ٢. على حاسوب الشبكة (ويندوز)

1. ثبّت Python 3 من python.org، وفعّل خيار **Add python.exe to PATH** أثناء التثبيت.
2. انسخ مجلد `zk_agent` كاملاً إلى الحاسوب، مثلاً `C:\zk_agent`.
3. افتح موجه الأوامر (cmd) داخل المجلد ونفّذ:
   ```
   python -m pip install -r requirements.txt
   ```
4. افتح `config.ini` بالمفكرة وعدّل:
   - `url` = عنوان الخادم من النافذة.
   - `token` = رمز الربط.
   - `ip` و `port` = عنوان الجهاز (الافتراضي 192.168.1.201 و 4370).
   - `password` = مفتاح الاتصال Comm Key (صفر إن لم يُضبط).
   - `since_date` = أول يوم تُرسَل بصماته (فارغ = أول الشهر الحالي).
5. اختبر الاتصال بالجهاز دون إرسال أي شيء:
   ```
   python zk_agent.py --test
   ```
   يجب أن يظهر الرقم التسلسلي وعدد المستخدمين (`users_count`) وعدد السجلات (`records_count`).
6. أول مزامنة يدوية لرؤية النتيجة:
   ```
   python zk_agent.py
   ```
7. جدولة التشغيل التلقائي كل خمس دقائق في الخلفية: شغّل `install_task.bat`
   (مرة واحدة). المهمة اسمها `TechnoZKAgent` وتعمل ما دام المستخدم مسجّلاً الدخول
   على الحاسوب. لإزالتها: `schtasks /delete /tn TechnoZKAgent /f`.

## ملاحظات

- السجل في `zk_agent.log` داخل المجلد، وآخر بصمة أُرسلت محفوظة في `state.json`.
- إعادة إرسال فترة سابقة: `python zk_agent.py --since 2026-01-01` (التكرار يُتجاهل في الخادم).
- لا يُعاد قراءة سجل الجهاز إن لم يتغيّر عدد سجلاته منذ آخر مرة.
- يُوقَف الجهاز (`disable_device`) أثناء القراءة فقط ثم يُعاد تشغيله دائماً، فلا تمتد
  القراءة إلا ثوانيَ معدودة. يمكن تشغيل برنامج ZKTeco في الوقت نفسه.
- إن فشل الاتصال عبر TCP يُعاد المحاولة عبر UDP تلقائياً (`udp_fallback`)، ويمكن فرض
  UDP بـ `force_udp = true`.
- سعة سجل K40 ثمانون ألف حركة؛ تظهر في النظام نسبة الامتلاء وتنبيه عند تجاوز ٩٠٪.
  التفريغ يتم من برنامج ZKTeco فقط بعد التأكد من وصول البصمات إلى النظام.
- يجب أن يكون توقيت الجهاز صحيحاً (توقيت مصر)؛ يُسجَّل تحذير إن اختلف عن الحاسوب بأكثر
  من خمس دقائق.
- الحاسوب يحتاج إنترنت (HTTPS) فقط، ولا يلزم فتح أي منفذ من الخارج.
