# 026 — بحث وفلترة الموردين + ملف المورد (Supplier 360)

نفس معالجة العملاء (025) مطبّقة على شاشة «الموردين والمدفوعات».

## الباك إند
- `services/supplier_profile_service.py` (Library-First، مرآة `customer_profile_service`):
  - `bulk_balances` — أرصدة كل الموردين في **استعلام واحد مجمّع** (بدل طلب لكل سطر = N+1).
  - `apply_filters` — بحث `q` على (الكود/الاسم/الهاتف/العنوان) + الحالة.
  - `filter_by_balance` — `due` (مستحق له) / `settled` (صفر) / `advance` (دفعنا مقدماً).
  - `profile` — الرصيد + إجماليات المشتريات/المرتجعات/المدفوعات + فواتير الشراء والمرتجعات
    وسندات الصرف والشيكات.
  - `record_detail` — تفاصيل أي سطر (`purchase | return | payment | cheque | entry`) بشكل
    موحّد، وكل استعلام **بيتأكد إن المستند يخص المورد ده** (مستند مورد تاني = 404 مش تسريب).
- `GET /suppliers` بقى يستقبل `q, active, balance_filter` وبيرجّع `balance` مع كل مورد.
- `GET /suppliers/{id}/profile` — ملف المورد كامل في نداء واحد.
- `GET /suppliers/{id}/records/{kind}/{record_id}` — تفاصيل أي سطر في الملف.
- `DELETE /suppliers/{id}?hard=true` — **حذف نهائي محمي**: يُرفض (409) لو على المورد أي حركة
  (فواتير شراء/سندات/شيكات/حركات دفتر) مع رسالة توجّه لإلغاء التفعيل. بدون `hard` = إلغاء تفعيل.

## الواجهة
- `pages/Suppliers.tsx`: شريط بحث + فلاتر (حالة الذمة/الحالة) + ملخّص (عدد الموردين/إجمالي
  المستحق/عدد الموردين اللي ليهم مستحقات)، والرصيد بيجي مع القائمة. **الضغط على السطر كله**
  يفتح ملف المورد. زر **حذف** + حقل الحالة داخل التعديل.
- `pages/SupplierProfile.tsx` (مسار `/suppliers/:supplierId`): صفحة داخلية بسهم رجوع، كروت
  ملخّص وتبويبات (نظرة عامة، كشف الحساب بفترة، فواتير الشراء، المرتجعات، سندات الصرف،
  الشيكات) — وكل سطر يفتح **بوباب**: فاتورة الشراء بمستند الفاتورة الكامل باللوجو، وسند الصرف
  بمستند السند بالمبلغ بالحروف، والقيد بطرفيه.

## الاختبارات
`tests/integration/test_supplier_search_profile.py` — البحث بالاسم/الكود/الهاتف، الرصيد مع
القائمة وفلتر المستحقات، تجميع ملف المورد، عزل مستندات مورد عن غيره، والحذف النهائي المحمي.

## ملاحظة
سند الصرف بيتطلب رصيد نقدي كافٍ في الخزينة (قاعدة موجودة في `voucher_service`) — الاختبار
بيموّل الخزينة برصيد افتتاحي قبل الصرف، زي الواقع.
